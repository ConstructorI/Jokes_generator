Генератор изображений, чат с ИИ и случайный текст.

Это десктопное приложение на **Python + PySide6**, которое объединяет три инструмента в одном интерфейсе:

1. **Генерация изображений** на основе текстового запроса.
2. **Общение с искусственным интеллектом** с сохранением истории.
3. **Создание случайного текста** на основе содержимого `.txt` файла методом цепей Маркова.

## 📌 Возможности

### 1. Генерация изображений

* Вводите текстовое описание на русском языке.
* Программа с помощью LLM формирует краткое англоязычное описание для генератора изображений.
* Поддержка нескольких моделей генерации (`FLUX.1-schnell`, `FLUX.1-merged`, `Stable Diffusion 3 Medium`) с автоматическим переключением при ошибках.
* Просмотр результата прямо в приложении и копирование изображения в буфер обмена.

### 2. Общение с ИИ

* Поддержка модели **Qwen/Qwen2** (72B и 7B fallback).
* История диалога отображается в отдельной вкладке.
* Возможность очистки истории одним кликом.

### 3. Генератор случайного текста

* Чтение указанного `.txt` файла.
* Создание случайного текста методом цепей Маркова.
* Регулировка количества слов в результате.

---

## 🖼 Интерфейс

Приложение состоит из трёх вкладок:

1. **Генерация изображения**

   * Поле ввода запроса.
   * Превью сгенерированного изображения.
   * Кнопка копирования картинки.

2. **Общение с ИИ**

   * Окно истории диалога.
   * Поле для ввода нового сообщения.
   * Кнопки отправки и очистки истории.

3. **Случайный текст из `.txt`**

   * Окно для отображения результата.
   * Поле для выбора файла и задания количества слов.
   * Кнопка генерации.
