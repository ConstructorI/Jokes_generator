# Jokes_generator (Генератор Шуток / Мультимедийный помощник)

Это приложение с графическим интерфейсом пользователя (GUI), созданное с помощью PySide6. Оно предоставляет три основные функции:

1.  **Генерация изображений:** Создание изображений на основе текстового описания.
2.  **Общение с ИИ:** Взаимодействие с языковой моделью Qwen для получения ответов на вопросы.
3.  **Генерация случайного текста:** Создание нового текста на основе статистики слов из предоставленного `.txt` файла.

## Возможности

*   **Вкладка "Генерация изображения":**
    *   Введите текстовое описание или тему в поле ввода.
    *   Приложение использует ИИ (Qwen) для создания краткого описания изображения на английском языке.
    *   Затем это описание передается модели генерации изображений (FLUX.1 или Stable Diffusion) для создания картинки.
    *   Сгенерированное изображение отображается в интерфейсе.
    *   Путь к сохраненному изображению отображается в строке ввода под изображением.
    *   Возможность скопировать путь к сохраненному изображению в буфер обмена.
*   **Вкладка "Общение с ИИ":**
    *   Задавайте вопросы ИИ в нижнем текстовом поле.
    *   История разговора отображается в верхнем текстовом поле.
    *   Есть возможность очистить историю разговора.
    *   ИИ настроен отвечать на русском языке.
*   **Вкладка "Случайный текст из txt":**
    *   Укажите путь к текстовому файлу (по умолчанию `проклятое.txt`).
    *   Задайте желаемое количество слов.
    *   Приложение проанализирует текст и сгенерирует новый, основываясь на частоте следования слов.
    *   Результат отображается в текстовом поле.

## Требования

*   Python 3.x
*   `numpy`
*   `gradio_client`
*   `PySide6`

## Установка

1.  Клонируйте репозиторий или скачайте файлы проекта.
2.  Убедитесь, что у вас установлен Python 3.x.
3.  Установите необходимые зависимости, например, с помощью pip:
    ```bash
    pip install numpy gradio_client PySide6
    ```
4.  Убедитесь, что файлы `main.py`, `MainWindow.py` и `res_rc.py` (если используется) находятся в одной директории.
5.  Для функции генерации текста подготовьте текстовый файл (например, `проклятое.txt`) и укажите его имя во вкладке "Случайный текст из txt".

## Использование

1.  Запустите скрипт `main.py`:
    ```bash
    python main.py
    ```
2.  Приложение откроется в отдельном окне с тремя вкладками:
    *   Переключайтесь между вкладками для доступа к разным функциям.
    *   Следуйте инструкциям на каждой вкладке (вводите текст, нажимайте кнопки "Начать генерацию", "Отправить", "Генерация" и т.д.).

## Важные замечания

*   Приложение использует `gradio_client` для взаимодействия с моделями ИИ через Hugging Face Spaces. Это требует подключения к Интернету.
*   Время генерации изображений и ответов ИИ зависит от доступности и нагрузки внешних сервисов.
*   При первом запуске может потребоваться время для установки соединения с моделями.
*   Приложение включает обработку ошибок для переключения между разными версиями моделей Qwen и различными моделями генерации изображений (FLUX.1, Stable Diffusion).
